# Soporte

[English](SUPPORT.md) · [Português](SUPPORT.pt-BR.md) · **Español**

## Dónde obtener ayuda

| Necesitas ayuda con | Dónde acudir |
|---|---|
| Instalar el plugin o conectar un cliente | Las [guías de instalación](install/README.es.md) y, después, un [issue en GitHub](https://github.com/universokobana/kobana-agent-marketplace/issues) |
| Tu cuenta Kobana, permisos, tokens o una duda sobre un producto | Soporte de Kobana: **suporte@kobana.com.br** o el [centro de ayuda](https://ajuda.kobana.com.br) |
| Servidores MCP para desarrolladores (transporte, scopes, ejemplos) | La [guía para desarrolladores](https://www.kobana.com.br/es/desarrolladores/mcp) y la documentación MCP de cada producto |
| Construir un agente sobre Kobana | [Agenda una conversación](https://www.kobana.com.br/es/agendar) |
| Una vulnerabilidad de seguridad | [SECURITY.es.md](SECURITY.es.md), nunca un issue público |

## Antes de abrir un issue

- Si ves menos herramientas de lo esperado, normalmente se debe al scope del token o a tus permisos en el panel, no a un bug.
- Prueba el test de conexión de la [guía para desarrolladores](https://www.kobana.com.br/es/desarrolladores/mcp).
- Nunca pegues en los issues tokens, datos de clientes ni logs completos de solicitudes con datos personales.
