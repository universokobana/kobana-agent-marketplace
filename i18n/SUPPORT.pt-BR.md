## Onde conseguir ajuda

| Você precisa de ajuda com | Procure |
|---|---|
| Instalar o plugin ou conectar um cliente | Os [guias de instalação](../install/pt-BR/README.md) e, depois, uma [issue no GitHub](https://github.com/universokobana/kobana-agent-marketplace/issues) |
| Sua conta Kobana, permissões, tokens ou uma dúvida sobre os produtos | Suporte Kobana: **suporte@kobana.com.br** ou a [central de ajuda](https://ajuda.kobana.com.br) |
| Servidores MCP para desenvolvedores (transporte, escopos, exemplos) | [Guia do desenvolvedor](https://www.kobana.com.br/desenvolvedores/mcp) e a documentação MCP de cada produto |
| Construir um agente sobre a Kobana | [Agende um bate-papo](https://www.kobana.com.br/agendar) |
| Uma vulnerabilidade de segurança | [SECURITY.pt-BR.md](SECURITY.pt-BR.md), nunca uma issue pública |

## Antes de abrir uma issue

- Ver menos ferramentas do que o esperado costuma ser o escopo do token ou as suas permissões no dashboard, não um bug.
- Faça o teste de conexão do [guia do desenvolvedor](https://www.kobana.com.br/desenvolvedores/mcp).
- Nunca cole tokens, dados de clientes ou logs completos de requisições com dados pessoais nas issues.
